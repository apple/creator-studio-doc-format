    Choose the kind of chart to show, from area and bar charts to radar and mixed charts.

    Area charts¶

    AreaChart¶

    class creator_studio_doc_format.core.AreaChart(*, preset_identifier='', title=None, caption=None, data=None, show_legend=True, legend=None, series=None, chart_colors=None, category_axis=None, value_axis=None, value_axis_secondary=None, identifier=None, geometry=None, aspect_ratio_locked=False, description=None, **extra_data)[source]¶

    A 2D area chart.

    Keynote draws each series as a filled region against a shared category axis and value axis.

    field title : Label | None = None¶

    The object’s title.

    field caption : Label | None = None¶

    The object’s caption, which Keynote always places below the object. If a caption is off, you still write it out with Label.is_visible set to false, so having a value doesn’t mean the caption shows.

    field data : ChartData | None = None¶

    The chart’s data grid, together with its plot direction and data-source mode. This data replaces the placeholder data a new chart starts with; when omitted, that placeholder data remains.

    field show_legend : bool = True¶

    A Boolean value that indicates whether the chart’s legend appears. This value is independent of the legend property, which sets the legend’s placement and text style rather than its visibility.

    field legend : ChartLegend | None = None¶

    The placement and label text style of the chart’s legend. This value doesn’t control whether the legend appears (see show_legend), and it only applies to a chart that has a legend.

    field series : list[ChartSeries] | None = None¶

    The styling and label formatting for individual data series. Each entry applies to the series named by its ChartSeries.series_index, or to the series at the same position when ChartSeries.series_index is omitted; entries that don’t correspond to a series in the data don’t have an effect.

    field chart_colors : list[ChartColor] | None = None¶

    The chart’s ordered series styles. A series takes the entry at its own position, and the chart’s style supplies any position without an entry or with an empty one, so the list doesn’t wrap. Entries past the last series also remain. Keynote reads one entry for each series style in the chart’s style and ignores any further entries.

    field category_axis : ChartCategoryAxis | None = None¶

    The category axis, along which Keynote lays out the chart’s categories. When omitted, the category axis keeps the appearance it inherits from the chart’s style.

    field value_axis : ChartValueAxis | None = None¶

    The primary value axis, which carries the numeric scale to measure the series against. When omitted, the value axis keeps the appearance it inherits from the chart’s style.

    field value_axis_secondary : ChartValueAxis | None = None¶

    The second value axis, used only by a two-axis chart that actually plots a series against a second value scale. On any other chart type, this value doesn’t have an effect.

    field identifier : str | None = None¶

    An identifier for this object that other objects use to refer to it. This identifier must be unique across the whole document.

    field geometry : Geometry | None = None¶

    The object’s position and size. If this value is absent, Keynote places the object automatically, with a default position and size for its kind.

    field aspect_ratio_locked : bool = False¶

    A Boolean value that indicates whether the object’s width-to-height ratio is locked when the object resizes. The lock doesn’t constrain the geometry property. If this property is absent, images, movies, and groups default to true, and other objects to false.

    field description : str | None = None¶

    The accessibility description for the object, read aloud by assistive technologies such as VoiceOver.

    field value_axis : ChartValueAxis | None = None¶

    The primary value axis, which carries the numeric scale to measure the series against. When omitted, the value axis keeps the appearance it inherits from the chart’s style.

    field value_axis_secondary : ChartValueAxis | None = None¶

    The second value axis, used only by a two-axis chart that actually plots a series against a second value scale. On any other chart type, this value doesn’t have an effect.

    field identifier : str | None = None¶

    An identifier for this object that other objects use to refer to it. This identifier must be unique across the whole document.

    field geometry : Geometry | None = None¶

    The object’s position and size. If this value is absent, Keynote places the object automatically, with a default position and size for its kind.

    field aspect_ratio_locked : bool = False¶

    A Boolean value that indicates whether the object’s width-to-height ratio is locked when the object resizes. The lock doesn’t constrain the geometry property. If this property is absent, images, movies, and groups default to true, and other objects to false.

    The accessibility description for the object, read aloud by assistive technologies such as VoiceOver.
