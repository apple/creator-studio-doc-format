    Presentation¶

    Build the presentation at a document’s root, and every model it contains.

    class creator_studio_doc_format.core.Presentation(*, preset_identifier='', theme=None, slide_size=None, slides, stylesheet=None, **extra_data)[source]¶

    A document’s root object, which describes one Keynote presentation.

    field theme : KeynoteTheme | None = None¶

    The theme that supplies the presentation’s slide layouts, styles, and backgrounds. If it’s absent, the default is Keynote’s White theme.

    field slide_size : Size | None = None¶

    The size of every slide in the presentation, in points. If it’s absent, a reader must supply the size, for example, from the theme, or reject the document.

    field slides : list[Slide] [Required]¶

    The presentation’s slides, in presentation order. Grouping in the slide navigator is expressed by each slide’s Slide.depth rather than by nesting arrays.

    Constraints:

    • min_length = 1

    field stylesheet : Stylesheet | None = None¶

    The presentation’s named styles: character, paragraph, list, line, shape, text box, image, movie, and table styles. The presentation’s objects and text can refer to these by their preset identifier. If this value is absent, Keynote uses the theme’s styles.

    Slides and placement¶

    Slides

    Build slides from the layouts a theme provides, and set the information a slide keeps about each object on it.

    Canvas

    Place objects on a slide, in a group, or inline in a paragraph, and set the properties they share.

    Positions

    Position an object and set how much room it reserves, in points.

    Slide content¶

    Text

    Add bodies of text and the containers that hold them, and set their paragraph and character properties.

    Lists

    Define bulleted and numbered list styles, their nesting levels, and the text, number, or image label each level shows.

    Links

    Attach links to text that open a URL or a file, jump to another slide, or exit the slideshow.

    Shapes

    Draw paths with a fill and a stroke, and connect objects with lines.

    Tables

    Add tables of cells, and arrange a text area in columns.

    Charts

    Add column, pie, scatter, and other charts to a slide.

    Media

    Add images, movies, and audio, and control how they play.

    Resource references

    Refer to the data that media, image fills, and image bullets use.

    Styles and appearance¶

    Themes and styles

    Apply a theme and the named styles that a presentation’s objects and text refer to.

    Fills

    Fill an area with a solid color, a gradient, or an image.

    Colors

    Specify the colors that displayed objects use.

    Shadows

    Add shadows and reflections around an object.

    Number formats

    Format numbers, such as those in a numbered list.

    Titles

    Add a title or caption to an object and set its properties.

    Common types¶

    Common types

    Describe groups of objects, sizes, labels, and dates with types that many others use.
