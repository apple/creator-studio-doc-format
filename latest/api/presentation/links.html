    Links¶

    Attach links to text that open a URL or a file, jump to another slide, or exit the slideshow.

    Hyperlink¶

    class creator_studio_doc_format.core.Hyperlink(*, preset_identifier='', file=None, program=None, slide_jump=None, url=None, **extra_data)[source]¶

    A clickable link attached to text.

    The target is a URL, a jump to another slide in the same presentation, a file, or an opaque program action.

    field file : str | None = None¶

    A relative or absolute file path or a file URL.

    field program : str | None = None¶

    An opaque action.

    The recognized value is exit_slideshow, which exits the slideshow. Keynote preserves unrecognized values verbatim and produces a warning on import.

    field slide_jump : SlideTarget | None = None¶

    A jump to another slide in the same presentation.

    field url : str | None = None¶

    An absolute URL with any scheme other than file:, such as https://..., mailto:..., tel:+..., or keynote://....

    SlideTarget¶

    class creator_studio_doc_format.core.SlideTarget(*, preset_identifier='', by_identifier=None, first=None, last=None, last_viewed=None, next=None, previous=None, **extra_data)[source]¶

    A target slide inside the same presentation, given either by identifier or by position.

    The five position cases have no settings of their own, can be written as a plain string, and are the dependable choice when authoring, because they are resolved at the moment the link is followed. by_identifier is meaningful only against identifiers belonging to the document being read.

    field by_identifier : str | None = None¶

    References the Slide.identifier of a slide in the same presentation. The value is stored exactly as supplied, and reading a presentation assigns every slide a fresh identifier, so a link whose value matches no identifier in the document being read does nothing when it’s followed.

    field first : Literal[True] | None = None¶

    The first slide in the presentation.

    field last : Literal[True] | None = None¶

    The last slide in the presentation.

    field last_viewed : Literal[True] | None = None¶

    The slide most recently viewed before the slide.

    field next : Literal[True] | None = None¶

    The slide immediately after the slide containing the link.

    field previous : Literal[True] | None = None¶

    The slide immediately before the slide containing the link.
