    Errors¶

    Handle the exceptions that opening or saving a document raises.

    Opening a document raises these exceptions when the file is corrupt or too new. save() can raise DocumentPackageError and DocumentVersionError too.

    DocumentPackageError¶

    class creator_studio_doc_format.core.DocumentPackageError(kind, message)[source]¶

    Bases: DocumentError

    The document’s bytes are invalid, and no Keynote export produces bytes like them.

    Parameters:

    The defect, also the kind attribute.

    message : str¶

    The text that str(error) returns.

    DocumentPackageErrorKind¶

    class creator_studio_doc_format.core.DocumentPackageErrorKind(str, Enum)[source]¶

    The defect that a document package error reports.

    Test kind to tell the defects apart. The message is often the text that zipfile raised. Every member is a defect in the bytes. A caller that skips any DocumentPackageError therefore stays correct for a member added later. A limit of the reader raises DocumentVersionError instead.

    str(kind) isn’t the member’s value. Interpolate kind.value to get the text.

    MALFORMED_ARCHIVE = 'malformed_archive'¶

    A ZIP archive that Python fails to read, such as a truncated or encrypted one, or one with a checksum that doesn’t match.

    MALFORMED_JSON = 'malformed_json'¶

    A payload file that isn’t valid JSON.

    The payload file is main.json. A bad manifest is defaulted instead.

    MALFORMED_PRESETS = 'malformed_presets'¶

    A presets file that isn’t a JSON array, a preset without properties, or a preset cycle that the payload actually reaches.

    The presets file is presets.json, and a preset’s properties are its properties key.

    MISSING_MAIN_FILE = 'missing_main_file'¶

    A package without a payload file.

    The payload file is main.json.

    NOT_A_PACKAGE = 'not_a_package'¶

    A file or stream that isn’t a ZIP archive, or a path that isn’t a regular file, such as a directory.

    DocumentVersionError¶

    class creator_studio_doc_format.core.DocumentVersionError[source]¶

    Bases: DocumentError

    An error that means this library is too old to read the document.

    The document can still be valid.

    The library raises this error when the package or any object declares a newer major version. Lenient decoding instead skips a value with a newer major version that a preset supplies for an optional or defaulted field, and leaves the field unset.

    The class itself names the cause, and the error has no kind. This is the one failure with a certain fix, which its message names.

    DocumentError¶

    class creator_studio_doc_format.core.DocumentError[source]¶

    The library can’t read the input far enough to validate it.

    Each subclass tells a batch caller what to do with the input:

    • DocumentPackageError means the data is wrong. Skip the file.

    • DocumentVersionError means the library is too old for the data. Stop the run and upgrade.

    Catch this base class only to report that the input couldn’t be read.

    A payload that parses but doesn’t match the models raises neither subclass. Because the mismatch can equally mean that the models are behind the exporter, it raises pydantic.ValidationError. A caller’s mistakes raise built-in exceptions.

    Pydantic wraps only a ValueError or an AssertionError that a validator raises, so a DocumentError raised inside a validator reaches the caller of model_validate unwrapped.
