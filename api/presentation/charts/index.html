    Charts¶

    Add column, pie, scatter, and other charts to a slide.

    Chart¶

    class creator_studio_doc_format.core.Chart(*, preset_identifier='', area=None, area_3d=None, bar=None, bar_3d=None, bar_interactive=None, bubble=None, bubble_interactive=None, column=None, column_3d=None, column_interactive=None, donut=None, line=None, line_3d=None, mixed=None, pie=None, pie_3d=None, radar=None, scatter=None, scatter_interactive=None, stacked_area=None, stacked_area_3d=None, stacked_bar=None, stacked_bar_3d=None, stacked_column=None, stacked_column_3d=None, two_axis=None, **extra_data)[source]¶

    An object that plots a grid of data in a visual style such as column, pie, or scatter.

    Write a chart as an object with a single key, which names its chart type, such as column or pie, and holds that type’s settings. The chart type decides only how Keynote plots the series: every chart type uses the same chart data, so when you change a chart’s type, that change replots the existing series without rewriting the data.

    field area : AreaChart | None = None¶

    A line chart with the region between the line and the axis filled, one region for each series.

    field area_3d : Area3DChart | None = None¶

    A 3D area chart.

    field bar : BarChart | None = None¶

    Values as horizontal bars, one bar for each series within each category.

    field bar_3d : Bar3DChart | None = None¶

    A 3D bar chart.

    field bar_interactive : BarInteractiveChart | None = None¶

    An interactive bar chart, which shows one data set at a time.

    field bubble : BubbleChart | None = None¶

    A scatter chart whose third value sets the area of each point.

    field bubble_interactive : BubbleInteractiveChart | None = None¶

    An interactive bubble chart, which shows one data set at a time.

    field column : ColumnChart | None = None¶

    Values as vertical bars, one bar for each series within each category.

    field column_3d : Column3DChart | None = None¶

    A 3D column chart.

    field column_interactive : ColumnInteractiveChart | None = None¶

    An interactive column chart, which shows one data set at a time.

    field donut : DonutChart | None = None¶

    A pie chart that appears as a ring with an open center.

    field line : LineChart | None = None¶

    Values as points joined by a line, with one line for each series.

    field line_3d : Line3DChart | None = None¶

    A 3D line chart.

    field mixed : MixedChart | None = None¶

    A mixed chart.

    Each series can appear as columns, as a line, or as an area. For more information on mixed charts, see ChartSeries.mixed_series_type.

    field pie : PieChart | None = None¶

    One series as wedges of a circle, with each wedge sized by its share of the total.

    field pie_3d : Pie3DChart | None = None¶

    A 3D pie chart.

    field radar : RadarChart | None = None¶

    Categories that appear around a circle, with each series appearing as a closed outline through its values.

    field scatter : ScatterChart | None = None¶

    Each series appears as a plot of pairs of X and Y values against two value axes, rather than against categories.

    field scatter_interactive : ScatterInteractiveChart | None = None¶

    An interactive scatter chart, which shows one data set at a time.

    field stacked_area : StackedAreaChart | None = None¶

    Filled regions that stack on one another, so the outer edge is the category total.

    field stacked_area_3d : StackedArea3DChart | None = None¶

    A 3D stacked area chart.

    field stacked_bar : StackedBarChart | None = None¶

    Horizontal bars with series that stack end to end, so each bar’s length is the category total.

    field stacked_bar_3d : StackedBar3DChart | None = None¶

    A 3D stacked bar chart.

    field stacked_column : StackedColumnChart | None = None¶

    Vertical bars with series that stack end to end, so each column’s height is the category total.

    field stacked_column_3d : StackedColumn3DChart | None = None¶

    A 3D stacked column chart.

    field two_axis : TwoAxisChart | None = None¶

    A two-axis chart.

    This type of chart plots each series against either the primary or the secondary value axis; for more information about axes, see ChartSeries.y_axis_selection. Each series can appear as columns, as a line, or as an area. For more information, see ChartSeries.mixed_series_type.
