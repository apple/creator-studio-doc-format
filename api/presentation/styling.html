    Themes and styles¶

    Apply a theme and the named styles that a presentation’s objects and text refer to.

    KeynoteTheme¶

    class creator_studio_doc_format.core.KeynoteTheme(*, preset_identifier='', name=None, locale=None, slide_layouts=None, **extra_data)[source]¶

    The Keynote theme a presentation is based on.

    A theme provides the presentation’s default slide layouts, styles, and background. It’s chosen by its name, as shown in Keynote, and slide_layouts can replace the layouts it provides.

    field name : str | None = None¶

    The name of the theme to base the presentation on, as shown in Keynote’s theme chooser (for example, White or Gradient). Because the name is localized, pair it with locale. Themes in My Themes are matched before built-in ones, and a name that matches nothing, like an absent name, falls back to the White theme. When Keynote exports a presentation whose custom theme isn’t in My Themes, it writes White here, so the presentation opens in the White theme even where that theme is available.

    field locale : str | None = None¶

    The locale of the theme name given in name. If it’s absent, the system locale is used. The value is a BCP 47 language identifier, such as en_US or en-u-nu-thai-ca-buddhist, or an ICU-style identifier, such as en@calendar=buddhist;numbers=thai.

    field slide_layouts : list[SlideLayout] | None = None¶

    The slide layouts to use in place of the ones the theme provides. If it’s present, the list replaces the theme’s own layouts entirely and must contain at least one entry. Each entry’s name must be unique within the theme, because a slide selects its layout by identifier or name. If it’s absent, it defaults to the theme’s layouts.

    Constraints:

    • min_length = 1

    Stylesheet¶

    class creator_studio_doc_format.core.Stylesheet(*, preset_identifier='', line_styles=None, shape_styles=None, textbox_styles=None, image_styles=None, movie_styles=None, table_style_collections=None, character_styles=None, paragraph_styles=None, list_styles=None, **extra_data)[source]¶

    A collection of styles to use as presets for various objects in a document.

    field line_styles : list[ShapeStyle] | None = None¶

    The preset styles that you can apply to lines and connection lines. If you omit this property, it defaults to the document’s built-in line styles.

    field shape_styles : list[ShapeStyle] | None = None¶

    The preset styles that you can apply to shapes. If you omit this property, it defaults to the document’s built-in shape styles.

    field textbox_styles : list[ShapeStyle] | None = None¶

    The preset styles that you can apply to text boxes. If you omit this property, it defaults to the document’s built-in text box styles.

    field image_styles : list[MediaStyle] | None = None¶

    The preset styles that you can apply to images. If you omit this property, it defaults to the document’s built-in image styles.

    field movie_styles : list[MediaStyle] | None = None¶

    The preset styles that you can apply to movies. If you omit this property, it defaults to the document’s built-in movie styles.

    field table_style_collections : list[TableStyleCollection] | None = None¶

    The preset table styles. Each entry groups the styles that make up one table style preset: the table as a whole, its cell borders, and the cell and text styles that the body, header rows, header columns, and footer rows use.

    field character_styles : list[CharacterStyle] | None = None¶

    The preset character styles that you can apply to a range of text. If you omit this property, it defaults to the document’s built-in character styles.

    field paragraph_styles : list[ParagraphStyle] | None = None¶

    The preset paragraph styles that you can apply to whole paragraphs. If you omit this property, it defaults to the document’s built-in paragraph styles.

    field list_styles : list[ListStyle] | None = None¶

    The preset list styles, which control bullets and numbering. If you omit this property, it defaults to the document’s built-in list styles.

    ShapeStyle¶

    class creator_studio_doc_format.core.ShapeStyle(*, preset_identifier='', name=None, properties, **extra_data)[source]¶

    A preset for shapes, text boxes, lines, and connection lines.

    It covers fill, border, opacity, shadow, reflection, and the default layout of the text inside.

    field name : str | None = None¶

    The name of the style as shown in Keynote. It’s absent for styles that have no name.

    field properties : ShapeProperties [Required]¶

    The properties that make up the style. When a preset_identifier is present, the entry is only a reference and carries no property values; otherwise, this is the style’s complete set of resolved properties.

    ShapeProperties¶

    class creator_studio_doc_format.core.ShapeProperties(*, preset_identifier='', stroke=Override.not_set(), opacity=Override.not_set(), reflection=Override.not_set(), shadow=Override.not_set(), fill=Override.not_set(), head=Override.not_set(), tail=Override.not_set(), layout_properties=None, paragraph_properties=None, **extra_data)[source]¶

    The appearance that a shape style applies.

    field stroke : Override[Stroke] = Override.not_set()¶

    The stroke or border drawn around the shape or, for a line or connection line, the stroke drawn along the line itself.

    field opacity : Override[float] = Override.not_set()¶

    The opacity of the shape, in the range 0 to 1.

    field reflection : Override[Reflection] = Override.not_set()¶

    The reflection of the shape.

    field shadow : Override[Shadow] = Override.not_set()¶

    The shadow cast behind the shape.

    field fill : Override[Fill] = Override.not_set()¶

    The fill used to decorate the interior of the shape. null clears the fill; if the key is omitted, the fill is inherited, and with no fill to inherit, the shape is unfilled.

    field head : Override[LineEnd] = Override.not_set()¶

    The head end of a line or connection line, drawn at its end point.

    field tail : Override[LineEnd] = Override.not_set()¶

    The tail end of a line or connection line, drawn at its start point.

    field layout_properties : LayoutProperties | None = None¶

    A set of properties defining how text is laid out inside the shape: padding, columns, and vertical alignment. It’s absent when the style sets none of these.

    field paragraph_properties : ParagraphProperties | None = None¶

    A set of properties that define the default paragraph formatting for text inside the shape. It’s absent when the style carries no default.
